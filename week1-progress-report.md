# Week 1 Progress Report

## Project Title
Cohort Retention Analysis and Customer Lifetime Value (CLTV) Analysis Using E-Commerce Data

## Introduction
The objective of this project is to analyze customer purchasing behavior using Cohort Analysis and Customer Lifetime Value (CLTV) techniques. 
The project aims to identify customer retention patterns, understand churn behavior, and evaluate the long-term value of customers 
to support data-driven business decisions.

## Week 1 Progress Summary
During Week 1, the team focused on project planning, dataset understanding, repository setup, documentation, data preprocessing and exploratory analysis.
The primary goal was to establish a strong foundation for retention and customer value analysis in the upcoming weeks.

## Work Completed

### 1. Project Setup and Documentation
* GitHub repository was created and organized for collaborative development.
* Project objectives, scope, and team details were documented.
* Detailed documentation on Cohort Analysis, customer retention, churn patterns, and CLTV concepts was prepared.
* Dataset details, schema overview were documented.

### 2. Dataset Selection and Understanding
* The Online Retail E-Commerce Dataset was selected from Kaggle.
* Dataset structure, attributes, and business relevance were studied.
* Key fields required for retention and CLTV analysis were identified.

### 3. Data Cleaning and Preprocessing
* Missing Customer IDs were handled.
* Cancelled transactions and invalid records were removed.
* Revenue-related features were created.
* A cleaned dataset was prepared for Cohort Retention Analysis.

### 4. Exploratory Data Analysis (EDA)
* Customer and country-level analysis was performed.
* Revenue-based analysis was conducted to understand business performance.
* Monthly revenue trends were examined.
* Top-performing customers and revenue-generating regions were identified through visualizations.

## Key Insights and Learnings
* Cohort Analysis helps track customer retention behavior over time.
* Customer churn patterns can be identified through retention analysis.
* CLTV helps estimate the long-term value generated by customers.
* Data preprocessing plays a critical role in ensuring reliable analytical results.

## Challenges Encountered
* Understanding project requirements and analytical workflow.
* Selecting and validating a suitable dataset.
* Coordinating responsibilities among team members.
* Preparing the dataset for further retention analysis.

## Plan for Week 2
* Create customer cohorts based on first purchase month.
* Generate the Cohort Retention Matrix.
* Calculate retention rates across cohorts.
* Analyze retention trends and customer behavior.
* Prepare the foundation for AOV, Purchase Frequency, and CLTV calculations.

## Conclusion
Week 1 objectives were successfully completed. 
The project repository, documentation, exploratory analysis, and data preprocessing activities have established a strong foundation for Cohort Retention Analysis
and Customer Lifetime Value calculations in the upcoming phases of the project.
